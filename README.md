# PepMetaStack

### Synergizing Biological Priors via Stacking Meta-Regression for Antimicrobial Activity Prediction

This repository provides the implementation of **PepMetaStack**, a stacking meta-regression framework that integrates protein language model representations with biologically informed sequence features for antimicrobial activity prediction.

## Training

The main training script is `train.py`.

```bash
python train.py
```

Additional training and experimental scripts are available in the repository.

## Dataset

The datasets used in this study include:

- **Minimum Inhibitory Concentration (MIC)** datasets
- **Hemolytic activity** dataset
- **General antimicrobial peptide (AMP)** dataset

The datasets are publicly available at:
